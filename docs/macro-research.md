# マクロ機能の調査（2026-11-18）

「キー 1 つで、決まった操作の並び（キー入力と待ち時間）を再生する」機能を、F75J の自作ファームとキー配置エディタに入れるための調査。

> **v0.6.0 で、下の「案 A」のとおりに実装した。** 実装の要点は、この資料の最後の「5. 実装したもの」を参照。

## 1. 今あるもの

| どこ | 中身 | F75J で使えるか |
|---|---|---|
| 出荷時のファーム ＋ 公式アプリ | 記録、キーごとの時間の編集、繰り返し（回数 / 離すまで / 別のキーを押すまで）（[aula-app-features.md](aula-app-features.md)） | 自作ファームに書き換えると使えない。ファーム内のマクロの保存の形は未解析 |
| 移植版の `aula_macro.c`（`MACRO_TG`） | 「自動打鍵」。ランダムな文字を打っては消すだけ。好きな操作を記録する機能ではない | そのままでは役に立たない |
| SMK（GM610 用）の `macro_store.h` / `gm610_macro.c` | 本物のマクロ。PC のアプリから USB で送って、キーボードの設定領域に保存する | F75J では無効。仕組みは参考になる |

### GM610 用マクロの仕組み（参考）

- 保存場所: 設定の保存領域（フラッシュ）の中の 240 バイト。
- 形: 最大 16 キーぶん。手順は 1 つ 2 バイトで、「キーを叩く（キーコード ＋ 修飾キー）」か「待つ（10ms 単位）」。
- PC から送る方法: USB の HID の Feature Report を使い、7 バイトずつ送る。
- 制限: 240 バイトしかないので、全部で 100 手順くらいまで。設定と同じ場所なので、書き込みのたびに設定のページも書き換わる。

### 出荷時のファームの参考情報（F75 の解析から）

- フラッシュの `0xD800` から、512 バイト × 10 個の「プロファイル」用のページがある（中身は空）。マクロの保存場所はまだわかっていない。

## 2. 作り方の案

### 案 A: キー表と同じく「書き込むときに差し込む」（おすすめ）

今のキー配置エディタのしくみ（[app-guide.md](app-guide.md)）に、そのまま乗せる。

- ファームの決まった場所に、マクロの表を置く。
  - 空いている場所: `0xE690`〜`0xEBFF`（約 1.4KB）。足りなければ、`0xD000` あたりまで広げることもできる（ふつうのコードは今 `0x8xxx` まで）。
- 手順の種類: 「キーを押す」「キーを離す」「キーを叩く」「待つ」。同時押し（Ctrl+C など）やメディアキーも入れられる。
- キーには `MACRO_1`〜`MACRO_16` のようなキーを割り当てる。
- 再生はファームのふだんのループで行い、時間は `tick_ms()`（タップと長押しで作った時計）で測る。
- 繰り返し方（1 回だけ / 押している間くり返す / もう一度押すまでくり返す）も入れられる。
- アプリ: マクロの一覧と、手順を並べる編集画面。エディタの窓の中でキーを押して記録することもできる（WebView2 でキー入力を受け取れる）。

**よい点**: USB の通信を作らなくてよい。今のチェック（コンパイラの数値との照合）もそのまま使える。
**弱い点**: マクロを変えるたびに、ファームの書き込みが要る（今のキー配置と同じ）。

### 案 B: GM610 のように USB で送って保存する

- 書き込みなしで、すぐ反映できる。
- ただし、ファームの USB の通信処理、保存処理、アプリ側の USB 通信を作る必要があり、手間が大きい。保存場所も 240 バイトしかないので、広げる工夫が必要。

## 3. 注意点

- 文字を打つマクロは、「キーを押した」という信号として送る。そのため、PC 側の日本語入力がオンかオフかで、結果が変わる。
- 日本語配列として送る（PC 側を日本語キーボードとして設定している前提）。記号の位置は、日本語配列の刻印に合わせて変換する必要がある。
- 長い待ち時間や長いマクロの再生中も、ほかのキーは使えるようにしておく（ふだんのループを止めない作り）。

## 4. 次にやるなら

1. 案 A で、ファームにマクロの表（`0xE690` 以降）と再生処理を足す。
2. 変換プログラムとチェックを、マクロの表に対応させる。
3. エディタに「マクロ」の画面（一覧と、手順の編集・記録）を足す。

## 5. 実装したもの（v0.6.0）

| 場所 | 中身 |
|---|---|
| `0xE690` | `umacro_dir[16][2]`: マクロごとに [手順の開始位置, 繰り返し方（0 = 1 回だけ、1 = 押している間、2 = もう一度押すまで）] |
| `0xE6D0`〜`0xEBFF` | `umacro_steps[332][2]`: [種類, 値]。種類は 0 = 終わり、1 = 叩く、2 = 押す、3 = 離す、4 = 待つ（ms） |
| `aula_umacro.c` | 再生処理。ふだんのループで動き、押す・離すの間に 12ms 待つ。ほかのマクロを押すと、今のマクロは止まる |
| キー | `MACRO_1`〜`MACRO_16`（マクロの中では使えない） |
| `keymap.json` | `"macros": [{"name", "mode": "once/hold/toggle", "steps": [["tap", "Ctrl+C"], ["delay", 100], ["text", "Hello"], ...]}]` |
| エディタ | マクロの一覧、手順の編集（並べ替え、削除）、記録（窓の中で押したキーと待ち時間を記録） |

- 「文字を打つ」は、1 文字につき手順 1 つになる（Shift が要る文字は Shift+キー）。全部で 332 手順まで。
- ファームのキー表の見出しは第 3 版（マクロ数 16 を追加）。
- 2026-11-19: 実機で確認した（「文字を打つ: Hello」を Fn + F3 に割り当てて、正しく打てた）。
