# キー配置エディタ（アプリ）

ロードマップ 3 段目の成果物。インストーラーで入れれば、Python などの準備なしで使える。

## 使う人向け

1. `dist\AULA-F75J-Keymap-Setup-<版>.exe` を実行してインストールする（管理者の権限は要らない）。
2. スタートメニューの「AULA F75J キー配置エディタ」を起動すると、専用の窓が開く（v0.4.0 から。窓を閉じるとアプリも終わる）。
3. キーボードの絵でキーをクリックし、右側で割り当てを選ぶ。
   - 画面は、上のバーの「キー配置」「マクロ」「ライト」で切り替える。
   - いちばん上でプロファイルを選ぶ（＋ 追加 / 名前を変える / 削除）。キーボードで切り替えるには、どこかのキーに「プロファイル」の項目のキーを割り当てる。
   - プロファイルの下に「プロファイルの行き来」の検証結果が出る。行き止まり（プロファイル 1 に戻れないプロファイル）があると赤で知らせ、書き込む前にも確認する。ベース層・Fn 層（Fn キーがあるときだけ）・ノブ・マクロの中の切り替えを調べ、作っていない番号（中身はプロファイル 1 と同じ）を「次のプロファイル」で通る場合も含めて判定する。
   - キーボードの絵の下の「ノブ」で、左回し・押す・右回しを設定できる。
   - 「マクロ」の画面で、マクロを作る（手順を並べるか、「記録」でキー操作を記録する）。キーへの割り当ては「割り当て」の「マクロ」から。
   - 「割り当て」の上の検索欄に打つと、すべての種類から探して一覧にする（英字の名前でも、日本語の説明（例:「音量」「コピー」）でも探せる。マクロの名前でも探せる）。Enter でいちばん合うものを割り当てる。「Ctrl+Alt+DEL」のような一覧にない組み合わせや QMK のキー名も、そのまま割り当てられる。Esc で検索をやめる。種類から選ぶときは、検索欄の下で、まとまり（キー / ショートカット / その他）→ 種類の順に選ぶ。
   - マクロの手順の欄では、打った文字に合う候補が出る。「Ctrl+」のあとには、同時押しにできるキーだけが出る。↑↓ で選んで Enter か Tab で決める。
4. キーボードをケーブルでつなぎ、右下の「キーボードに反映する」を押す（画面ではずっと右下に浮かんでいる）。
5. 終わったら、窓の ✕ で閉じる（保存していない変更があるときは、確認が出る）。

- 割り当ての選択肢には、説明つきの便利なコマンドを並べてある。「修飾・日本語入力」（日本語入力オン = `LNG1`、英数 = `LNG2`、入力方法の切り替えなど）、「よく使うコマンド」（編集）、「Windows の操作」（タスクビュー、仮想デスクトップ、画面の切り取り、絵文字、スリープなど）、「ブラウザ」（タブ、戻る・進む、再読み込みなど）。
- 「ライト」の画面で、光り方（15 種類＋消灯）・明るさ（10 段階）・速さ（5 段階）・色（7 色＋虹色）・流れる向きを選べる。「書き込むときに、このライトの設定もキーボードに反映する」にチェックを入れて書き込むと、書き込み後に一度だけ反映される（ファームの 0xEBF0 の 16 バイト。書き込みごとに番号を変え、キーボードは新しい番号のときだけ反映する）。そのあと Fn + キーで変えた設定は、次に書き込むまで残る。
- **設定のやりとり**（右上の「メニュー」。「保存だけする」もここにある）
  - 「キーボードから読み込む」: キーボードに保存してある設定ファイルを読み出して、エディタに読み込む（キーボードを正とする）。キーボードは一度つながり直す。読み込んだ内容は、この PC の保存にもなる。
  - 「ファイルに書き出す」「ファイルから読み込む」: 設定を 1 つのファイル（keymap.json と同じ形）でやりとりする。別の PC へ持っていく、バックアップ、人に渡す、などに使う。ファイルから読み込んだ設定は、書き込むまでキーボードには反映されない。
  - 書き込むと、設定ファイルそのもの（名前なども全部、圧縮して約 1KB）が、キーボードの 0xD000〜0xDFFF（4KB）にも入る（`tools/config_store.py`）。
- **反映の状態**（右下のボタンの左）: 「反映済み」（緑）「未反映の変更あり」（橙）「まだ反映していません」（灰）。最後に反映した / 読み込んだ設定の指紋（`%APPDATA%\AULA F75J Keymap\sync.json`）と、エディタの内容をくらべて表示する。メッセージ（反映中、エラーなど）は、ボタンの上に吹き出しで出る。
- 「すべて初期値に戻す」（右上の「メニュー」）で、キー配置・プロファイル・ノブ・マクロを、すべて最初の状態に戻せる。「元に戻す」で取り消せる。キーボードには、「キーボードに反映する」を押すまで反映されない。

- キー配置は `%APPDATA%\AULA F75J Keymap\keymap.json` に保存される。
- アプリはキーボードから今の配置を読み出せない。画面に出ているのは、最後にアプリで保存した配置。
- 初めてこのアプリで書き込む前のキーボードには、自作ファーム（F75J 用 SMK）を一度入れておく必要はない。書き込むと、ファームごと入る。

## しくみ

- 同梱のファーム（`firmware-base.hex`）には、0xE000 番地にキー表の場所がある（[firmware-analysis.md](firmware-analysis.md) とは別に、自作ファーム側で用意したもの）。
  - 0xE000: 見出し `F75JKMAP`、版 2、行数 6、列数 17、層の数 8、プロファイル数 4
  - 0xE010: キー表 8 層 × 6 行 × 17 列 × 2 バイト（リトルエンディアン）。プロファイル p の層は 2p（ベース）と 2p+1（Fn）
  - 0xE670: ノブの表 8 層 × [左回し, 右回し] × 2 バイト
  - 0xE690: マクロの表（一覧 16 個 + 手順 332 個、各 4 バイト、0xEBFF まで）。見出しは第 3 版
- 書き込むときは、そのキー表だけを差し替えて（`tools/firmware_image.py`）、同梱の sinowisp で書き込む。
- キー名 → 数値の対応は `keycodes.json`（ファームのソースから書き出したもの）。

## 作る側の手順（この PC）

1. ファームを作り直したとき: `powershell -ExecutionPolicy Bypass -File tools\build-f75j.ps1`
   - `app\firmware-base.hex` と `app\keycodes.json` も更新される。
   - `tools\check_layout.py` が、キー表の場所と数値がコンパイラと一致することを確かめる。
2. 配布物を作る: `powershell -ExecutionPolicy Bypass -File tools\package.ps1`
   - `dist\F75JKeymap.exe`（アプリ本体）と `dist\AULA-F75J-Keymap-Setup-<版>.exe`（インストーラー）ができる。
   - 必要なもの: PyInstaller（`python -m pip install pyinstaller`）、pywebview（`python -m pip install pywebview`）、Inno Setup 6（`winget install JRSoftware.InnoSetup`）
3. 開発中に画面だけ試す: `python app/server.py`（窓で開く）、`python app/server.py --browser`（ブラウザで開く）。このときの保存先は `keymap/keymap.json`

## ファイル

| 場所 | 中身 |
|---|---|
| `app/server.py` | アプリ本体（Python 標準ライブラリだけ） |
| `app/index.html` | 画面 |
| `app/default-keymap.json` | 「初期値に戻す」の基準（出荷時に近い配置） |
| `app/keycodes.json`, `app/firmware-base.hex` | ビルドで作られる同梱物 |
| `app/icon.ico` | アプリのアイコン（`python tools/make_icon.py` で作り直す） |
| `app/licenses/` | 同梱物のライセンス（SMK・sinowisp・Python・pywebview など。`python tools/collect_licenses.py` で集め直す） |
| `installer/f75j-keymap.iss` | インストーラーの設定 |
