# キー配置の変え方

キー配置は [keymap/keymap.json](../keymap/keymap.json) に書いてある。これを書き換えて、ビルドして、書き込む。

## 手順

1. `keymap/keymap.json` を書き換える（メモ帳や VS Code で開く）。
2. ビルドする。キー配置にまちがいがあれば、ここで場所と理由を教えてくれる。
   ```
   powershell -ExecutionPolicy Bypass -File tools\build-f75j.ps1
   ```
3. 書き込む（キーボードはケーブルでつなぐ）。
   ```
   .\sinowisp.exe write -d aula-f75 firmware\aula-f75j_smk.hex
   ```

## ファイルの形

- v0.5.0 から、いちばん外側は `profiles`（プロファイル、最大 4 つ）。各プロファイルが `name`、`knob`、`layers` を持つ。
  - `knob`: ノブの回転。`{"base": [左回し, 右回し], "fn": [左回し, 右回し]}`。初期値はベースが `VOLD` / `VOLU`、Fn は `___`（ベースと同じ）。ノブを押したときの動きは、1 行目のいちばん右のキー。
  - キーボードでプロファイルを切り替えるには、どこかのキーに `PROF_1`〜`PROF_4`（その番号へ）か `PROF_NEXT`（次へ）を置く。切り替えたプロファイルは、電源を切っても覚えている。
  - 使っていないプロファイル番号に切り替えると、プロファイル 1 と同じ配置になる。
  - **非常口**: どのプロファイルでも、Esc と F12（の位置のキー）を一緒に 2 秒押すと、プロファイル 1 に戻る。割り当てを変えても消えない（v0.7.0 から）。
  - プロファイルが切り替わると、約 1 秒間、ライトが全部消えて、切り替わった先の番号のキー（1〜4）だけが白く光る（切り替えキーでも非常口でも同じ）。
  - 古い形（`layers` だけのファイル）は、アプリが読み込むときに「プロファイル 1」に直す。
- 各プロファイルの `layers` は、次の 3 つの層で固定（v0.3.0 から）。
  - `base`（ベース層）: ふだん押したときのキー。タップ層を設定したキーでは、「長押し」のときの動きになる。
  - `fn`（Fn 層）: `FN` を押している間のキー。`___` はベース層と同じ。
  - `tap`（タップ層）: 軽く叩いたときのキー。`___` ならタップは使わない（ふつうのキー）。
- タップ層にキーを置いたら、同じ位置のベース層は **修飾キー（`LCTL` など、`Ctrl+Shift` のような組み合わせも可）か `FN`** にする。
  - 例: CapsLock のベース層を `LCTL`、タップ層を `ESC` → タップで Esc、長押しで Ctrl
  - 例: スペースのベース層を `FN`、タップ層を `SPC` → タップでスペース、長押しで Fn 層
- 長押しの判定: `tapping_term`（ミリ秒、100〜1000、初期値 200）より長く押すか、押している間にほかのキーを押すと「長押し」。エディタではタップ層を開くと設定できる。全プロファイル共通。ファームのキー表の見出し（0xE00E〜0xE00F）に入る。
- 各層の `keys` は 6 行。キーボードの見た目どおりに、左上から右へ並べる。

| 行 | キーの数 | 並び |
|---|---|---|
| 1 | 14 | Esc, F1–F12, ノブ押し |
| 2 | 16 | 半/全, 1–0, -, ^, ¥, BS, Del |
| 3 | 14 | Tab, Q–P, @, [, PgUp |
| 4 | 15 | Caps, A–L, ;, :, ], Enter, PgDn |
| 5 | 15 | LShift, Z–/, ろ, RShift, ↑, End |
| 6 | 11 | LCtrl, Win, Alt, 無変換, Space, 変換, かな, Fn, ←, ↓, → |

キー名の並びは、日本語配列の刻印とは違う名前になるところがある（例: `@` のキーは `LBRC`）。`keymap.json` の今の中身が、そのまま見本になる。

## キー名の書き方

| 書き方 | 意味 | 例 |
|---|---|---|
| キー名 | 普通のキー。`KC_` は付けても付けなくてもよい | `A`, `ENT`, `F5`, `HOME`, `KC_TAB` |
| 修飾キー + キー | 同時押し。`Ctrl` `Shift` `Alt` `Win`（右側は `RCtrl` など） | `Ctrl+C`, `Alt+Tab`, `Win+E`, `Ctrl+Shift+ESC` |
| 修飾キーだけの組み合わせ | 長押し側に使う | `Ctrl+Shift` |
| `FN` | 押している間だけ Fn 層に切り替える。ベース層にだけ置ける | `FN`（= `MO(1)`） |
| `___` | Fn 層: ベース層と同じ ／ タップ層: タップを使わない | |
| `MT(…)` / `LT(…)` | 古い書き方。読み込むと、ベース層とタップ層に分けて直される | `MT(Ctrl, ESC)` |
| `NO` | 何もしない | |

### よく使うキー名

| 種類 | 名前 |
|---|---|
| 日本語配列 | `ZENKAKU`（半/全）, `YEN`（¥）, `RO`（ろ）, `MUHENKAN`, `HENKAN`, `KANA` |
| 記号（日本語配列での刻印） | `MINS`(-), `EQL`(^), `LBRC`(@), `RBRC`([), `SCLN`(;), `QUOT`(:), `BSLS`(]), `COMM`(,), `DOT`(.), `SLSH`(/) |
| 編集 | `ENT`, `ESC`, `BSPC`, `TAB`, `SPC`, `DEL`, `INS`, `HOME`, `END`, `PGUP`, `PGDN` |
| 矢印 | `UP`, `DOWN`, `LEFT`, `RGHT` |
| 修飾キー | `LCTL`, `LSFT`, `LALT`, `LGUI`, `RCTL`, `RSFT`, `RALT`, `RGUI` |
| その他 | `CAPS`, `PSCR`, `SCRL`, `PAUS`, `APP`（メニュー）, `F1`–`F24` |
| メディア | `MUTE`, `VOLU`, `VOLD`, `MPLY`, `MNXT`, `MPRV`, `WHOM`（ブラウザ）, `MAIL`, `CALC` |
| ライト | `BRI_UP`, `BRI_DN`, `FX_NEXT`, `FX_PREV`, `CLR_NEXT`, `SPD_UP`, `SPD_DN`, `DIR_TOG` |
| 無線 | `LNK_BT1`–`LNK_BT3`, `RF_PAIR`, `RF_DIAG` |
| 特別 | `BOOT_HOLD`（3 秒押すと書き込み待ちの状態に入る）, `MACRO_TG`（自動打鍵） |
| マウス | `MS_BTN1`（左クリック）, `MS_BTN2`（右）, `MS_BTN3`（中）, `MS_BTN4` / `MS_BTN5`（戻る / 進む）, `DBLCLK_L` / `DBLCLK_R`（ダブルクリック）, `MS_WH_UP` / `MS_WH_DOWN` / `MS_WH_LEFT` / `MS_WH_RIGHT`（スクロール。押し続けるとくり返す）, `MS_UP` / `MS_DOWN` / `MS_LEFT` / `MS_RIGHT`（カーソル移動。押している間、だんだん速くなる） |

ほかのキー名は `third_party/smk_aulaF75/src/smk/keycodes.h` にある（QMK と同じ名前）。

## 例

CapsLock を Ctrl にする（ベース層の 4 行目の 1 個目）:
```json
["LCTL", "A", "S", ...
```

Fn + H / J / K / L を矢印キーにする（fn 層の 4 行目の 6〜9 個目）:
```json
["___", "___", "___", "___", "___", "___", "LEFT", "DOWN", "UP", "RGHT", "___", ...
```

## 今のところできないこと

- 層の切り替えキー（`FN`、`LT` など）は、ベース層にしか置けない。
- 同時押しとタップに使えるのは普通のキーだけ（メディアキーなどは使えない）。
- タップと長押し: 0.2 秒より長く押すか、押している間にほかのキーを押すと「長押し」になる。速く打つキーに `MT` を付けると、意図せず長押しになることがある。
- 文字列を打つマクロ。
- 同時押しキーを離すと、同じ修飾キーを手で押していても、その修飾キーも離された扱いになる。
- **Fn キーを 1 つも置かないと、ライトや無線の操作ができなくなる**。`BOOT_HOLD` もどこかに残しておくと安心。
