# ロードマップ

1. **解析と資料づくり**: ファームウェアを解析し、人間にも AI にもはっきり理解できる日本語の資料にまとめる。
   - 済み: チップの確認、バックアップ、JIS の配置（[f75j-matrix.md](f75j-matrix.md)）、基本資料（[firmware-analysis.md](firmware-analysis.md)）
   - 無線: F75 と同じ仕組みと確認済み
   - LED: キーと同じ 6 × 17 の並びと確認済み
   - 特殊機能: ほぼ解析済み（逆アセンブラ `tools/dis8051.py` を作成）
   - 残り: ライト設定の細かい意味、一部の特殊機能の意味
2. **書き換えプログラム**: 調査結果をもとに、ファームウェアを書き換えるプログラムをこの PC に置く。
   - 済み: F75J 用の自作ファームのビルド（手順は [flash-guide.md](flash-guide.md)）
   - 済み: 実機に書き込み、有線・2.4GHz・日本語配列のキーの動作を確認
   - 済み: キー配置ファイル `keymap/keymap.json` → ビルドの仕組み（[keymap-guide.md](keymap-guide.md)）。同時押し（Ctrl+C など）にも対応した
3. **GUI アプリ**: そのプログラムを育てて、画面から操作できるアプリにする。
   - 済み: キー配置エディタ（インストーラー版、環境構築なしで使える）。説明は [app-guide.md](app-guide.md)
   - v0.2.0: タップと長押しの使い分け（MT / LT）を追加
   - v0.3.0: 層を「ベース・Fn・タップ」の 3 つに固定。タップは「タップ層」で設定する（[issues.md](issues.md) #1 を解決）
   - v0.3.1: タップ層では、タップを使えるキー（ベース層が修飾キーか Fn）だけを選べるようにした
   - v0.3.2: 画面のタブを閉じると数秒でアプリが終わるようにした。インストーラーは、動いているアプリを終了させてから入れる
   - v0.4.0: ネイティブアプリ化（pywebview + WebView2 の専用の窓。閉じたら終わる）。メディア・アプリ起動のキーを Windows のアイコンフォント（Segoe Fluent Icons）で表示
   - v0.4.1: 元に戻す / やり直す（ボタンと Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z）
   - v0.5.0: ノブ（左回し・押す・右回し）に好きな機能を割り当て。プロファイル（最大 4 つ、キーで切り替え、電源を切っても覚えている）。ファームのキー表は第 2 版（0xE670 にノブの表）
   - v0.6.0: マクロ（16 個まで、叩く・押す・離す・待つ・文字を打つ、繰り返し 3 種類、記録）。詳しくは [macro-research.md](macro-research.md)
   - 2026-11-19: v0.6.0 を実機で確認（マクロ、ノブ、プロファイルの切り替え）。
   - v0.6.1: プロファイルの行き来の検証（行き止まり・たどり着けないプロファイルを知らせ、行き止まりがあれば書き込み前に確認）。全プロファイル共通のキー（グローバルキーバインド）は、作らないことにした（2026-11-19、ユーザーの判断）。
   - v0.7.0: 非常口。Esc と F12 を一緒に 2 秒押すと、どのプロファイルからでもプロファイル 1 に戻る（ファームが配線上の位置を直接見るので、割り当てに関係なく使える。`kb.c` の `escape_task`）
   - v0.8.0: キー名の入力欄に候補を出す。「すべて初期値に戻す」ボタン。選択肢に便利なコマンドを追加（日本語 / 英数、「Windows の操作」「ブラウザ」のグループ）
   - v0.8.1: Fn 層では、ベース層で Fn にしているキーを選べないようにした
   - v0.9.0: マウス操作（クリック、戻る・進む、ダブルクリック、スクロール、カーソル移動。有線は USB の Report ID 3、無線は短い枠の後ろ 7 バイト）。プロファイルが切り替わったときのライトの合図（切り替わった先の番号のキーが約 1 秒白く光る）。2026-11-19 に実機で確認（マウスは有線・2.4GHz とも、合図、非常口）公式ソフトの保存場所の調査は [official-app-storage.md](official-app-storage.md)
   - v0.10.0: ライトの設定（エディタで選び、書き込み後に一度だけ反映。ファームの 0xEBF0、見出しは第 4 版。この版を初めて書き込むと、キーボードの中の設定が一度初期値に戻る）
   - v0.11.0: タップと長押しを見分ける時間（100〜1000 ms）をエディタのタップ層で指定できるようにした（キー表の見出しの 14〜15 バイト目）
   - v0.11.1: Fn 層の同時押し（Win+E など）を押したまま先に Fn を離すと、Win などが押されたままになる不具合を修正（押したときの keycode を位置ごとに覚えて、同じものを離す。matrix.c の pressed_code）
   - v0.12.0: 設定のやりとり。書き込むと設定ファイルごとキーボード（0xD000〜0xDFFF）に保存し、「キーボードから読み込む」で戻せる。ファイルへの書き出し・読み込み。同期の状態の表示。2026-11-20 に実機で確認（書き込み、キーボードから読み込む、ファイルの書き出し・読み込み、同期の状態）
   - v0.13.0: 画面の整理（エディタだけの変更）。「キーボードに書き込む」を「キーボードに反映する」にして右下に浮かべ、反映の状態（反映済み / 未反映の変更あり / まだ反映していません）を横に出す。上のバーで「キー配置」「マクロ」「ライト」を切り替える。めったに使わない操作は右上の「メニュー」へ。「終了」ボタンをなくし、窓の ✕ で閉じる（保存していない変更があるときだけ確認）。割り当ては、検索欄＋2 段（キー / ショートカット / その他 → 種類）。「ろ」キーを「\」と表示。キーボードの接続は「接続中 / 未接続」
   - v0.13.1: アプリのアイコン（暗い地にキーが 1 つだけ黄色く光る。app/icon.ico、tools/make_icon.py で作る）。exe・窓・インストーラーに使う
   - v0.14.0: ファームのライトの表を、すべて自作に置き換えた（tools/gen_light_tables.py が、自分のキー配置と数式から作る。出荷時のファームの表は使わない）。同梱部品のライセンスの文を app/licenses に入れた（tools/collect_licenses.py）
   - Web アプリ版（WebHID）は、作らないことにした（2026-11-19、ユーザーの判断。自分の Windows PC で使うぶんには、インストール版で足りるため）
