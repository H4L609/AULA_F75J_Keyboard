## AULA F75J キー配置エディタ v0.14.0

AULA F75J（日本語配列）のすべてのキーを割り当てられるようにする、Windows 用のアプリです。

### 入れ方

1. 下の `AULA-F75J-Keymap-Setup-0.14.0.exe` をダウンロードして実行する（管理者の権限は要りません）。
2. 「AULA F75J キー配置エディタ」を起動する。
3. キーボードを USB ケーブルでつなぎ、割り当てを変えて、右下の「キーボードに反映する」を押す。

> [!WARNING]
> キーボードのファームウェアを書き換えます。自己責任で使ってください。

### この版の変更

- ライトの光り方に使う表を、すべて自分で作り直しました（色の輪、グラデーション、波紋、流れる波、きらめき、呼吸など）。出荷時のファームの表は使っていません。
  - 色の並びや呼吸の雰囲気は前とほぼ同じです。波紋の広がり方は少し変わり、¥ キーなども含めたすべてのキーが光るようになりました。
  - 新しい光り方は、この版で「キーボードに反映する」を押したあとから使われます。
- アプリに同梱している部品（Python、pywebview など）のライセンスの文を、インストール先の `licenses` フォルダに入れました。
