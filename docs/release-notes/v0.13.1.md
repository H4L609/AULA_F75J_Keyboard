## AULA F75J キー配置エディタ v0.13.1

AULA F75J（日本語配列）のすべてのキーを割り当てられるようにする、Windows 用のアプリです。

### 入れ方

1. 下の `AULA-F75J-Keymap-Setup-0.13.1.exe` をダウンロードして実行する（管理者の権限は要りません）。
2. 「AULA F75J キー配置エディタ」を起動する。
3. キーボードを USB ケーブルでつなぎ、割り当てを変えて、右下の「キーボードに反映する」を押す。

> [!WARNING]
> キーボードのファームウェアを書き換えます。自己責任で使ってください。

### この版の変更

- 画面を整理しました
  - 「キーボードに反映する」ボタンを右下に固定し、横に反映の状態（反映済み / 未反映の変更あり / まだ反映していません）を出す
  - 上のバーで「キー配置」「マクロ」「ライト」を切り替える
  - めったに使わない操作（保存だけする、キーボードから読み込む、ファイルに書き出す / 読み込む、すべて初期値に戻す）は右上の「メニュー」へ
  - 「終了」ボタンをなくし、窓の ✕ で閉じる（保存していない変更があるときだけ確認）
  - 割り当ては、検索欄と「キー / ショートカット / その他」→ 種類の 2 段で選ぶ
- アプリのアイコンを付けました
- 「＼ ろ」のキーを「\」と表示するようにしました
