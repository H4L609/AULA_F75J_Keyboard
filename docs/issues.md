## #1 層を追加できるのに、消せない・使い方がわからない

- 状態: **解決（v0.3.0）**。層を「ベース・Fn・タップ」の 3 つに固定し、「＋ 層を追加」をなくした。古い keymap.json の空の追加層は、読み込み時に自動で消える（中身がある場合はエラーで知らせる）。
- 報告: 2026-11-18（ユーザー）
- 場所: キー配置エディタ（`app/index.html` の「＋ 層を追加」）

**内容**
- 「＋ 層を追加」で 3 つ目以降の層を足せるが、足した層を消す方法がない。
- 足した層に切り替える手段が、画面からはわからない。
  - 実際には、ベース層のどこかに「層2」キー（`MO(2)`、「ライト・無線・層」の中にある）を置けば切り替えられる。ただ、そのことが画面のどこにも書かれていない。
- 間違って層を足すと、`keymap.json` に使われない層が残ったままになる。

**ユーザーの意見**
- 層を追加できなくてもよい（ベース層と Fn 層の 2 つで足りる）。

**直し方の案**
- 「＋ 層を追加」のボタンを消して、ベース層と Fn 層の 2 つだけにする（ユーザーの意見どおり。いちばん簡単）。
- 残す場合は、「層を消す」ボタンと、「層を使うには、ベース層に層キーを置く」という案内を足す。
- すでに足してしまった層は、中身が全部「下と同じ」なら、保存するときに自動で消す。
