# AULA Gasket Mechanical Keyboard アプリ 機能一覧

- 対象: 公式アプリ「AULA Gasket Mechanical Keyboard」 v2.0（`OemDrv.exe`）
- 場所: `C:\Program Files (x86)\AULA Gasket Mechanical Keyboard\`
- 調べ方: アプリは起動していない。画面の文言（`Text\Japanese\text.xml`）と F75 用の設定（`Dev\kb\F75\KB.ini`）を読んで整理した。
- 対応機種: F65 / F75 / F87J / F99J。F75 の設定名は「AULA F75 JIS」（USB 258A:010C、2.4G レシーバー 3554:FA09）。

印: ◎ = F75 の設定で有効と確認できた ／ ○ = 共通の機能 ／ × = F75 では使わない（ほかの機種用）

## 1. キー割り当て

| 機能 | 内容 | F75 |
|---|---|---|
| レイヤー | 「デフォルト」と「FN1」の 2 層を編集できる | ◎ |
| FN2 レイヤー | 画面の文言はあるが、F75 の設定には FN2 がない | × |
| キーボードのキー | ほかのキー、またはキーの組み合わせ（例: Ctrl+C）を割り当てる | ○ |
| マウス操作 | 左・右・中クリック、戻る・進む、上下スクロール、左右のダブルクリック | ○ |
| マルチメディア | 再生/一時停止、停止、前・次の曲、音量 ±、ミュート、画面の明るさ ± | ○ |
| アプリ起動 | メール、ブラウザ、マイコンピュータ、電卓、お気に入り、プレイヤー | ○ |
| よく使うコマンド | ウィンドウを閉じる、PC をロック、ファイル名を指定して実行、デスクトップ表示、拡大・縮小、タスクマネージャー、元に戻す、保存 | ○ |
| ロック・リセット | Win キーのロック、キーボードのロック、キーボードのリセット | ○ |
| マクロ | 作ったマクロをキーに割り当てる | ○ |
| 機能なし | キーを無効にする | ○ |
| キーを戻す | 1 キーずつ初期の割り当てに戻す | ○ |

## 2. マクロ

- 新規作成・名前の変更・コピー・削除。フォルダとサブフォルダで整理できる
- キー操作を記録（開始・停止）
- 編集画面: キーごとに開始時間・長さ・終了時間を直せる。表示倍率の変更、プレビュー、途中への挿入
- 繰り返し方: 回数を指定 ／ キーを離すまで ／ 別のキーを押すまで
- マクロの数には上限がある

| 光り方 | 速さ | 明るさ | 色を選ぶ |

| ブレス | ○ | ○ | ○ |
| ドリーミーレインボー | ○ | ○ | — |
| タッチで発光 | ○ | ○ | ○ |
| 雨の中を歩く | ○ | ○ | ○ |
| レインボールーレット | ○ | ○ | ○ |
| 波紋拡散 | ○ | ○ | ○ |
| 星屑 | ○ | ○ | ○ |
| 雪の上を跡なく歩く | ○ | ○ | ○ |
| 川の流れのよう | ○ | ○ | ○ |
| 波に乗って流れる | ○ | ○ | ○ |
| 影のように付き従う | ○ | ○ | ○ |
| サイン波 | ○ | ○ | ○ |
| 左右スキャン | ○ | ○ | ○ |
| 回転風車 | ○ | ○ | — |
| 7 色滝 | ○ | ○ | — |
| 花が咲き富をもたらす | ○ | ○ | — |

| カスタム | キーごとに色を塗る（ドラッグで複数選択可） | | |

- 明るさ 10 段階、速さ 5 段階
- 色: 単色 ／ 多色（ランダム）、カスタムカラーの追加
- 音楽に合わせて光る（音楽モード）: 10 パターン、単色/混色、ゲイン（自動計算あり）、スムーズ ◎（F75 用のデータあり）

## 4. 設定・その他

| 機能 | 内容 | F75 |
|---|---|---|
| プロファイル | FN+1〜FN+5 の 5 つを切り替え。インポート・エクスポート | ○ |
| スリープ時間 | ワイヤレス時に自動スリープ。1・1.5・2・3・4・5・10・15・20 分 | ◎ |
| キーデバウンス | チャタリング対策の値（段階）を変える | ◎ |
| 工場出荷時に戻す | キーボードの設定をすべて初期化 | ○ |
| デバイス情報 | 機種名、ファームのバージョン、アプリのバージョン | ○ |
| 電池残量 | 表示する機能はあるが、F75 では表示しない設定 | × |
| ファーム更新 | 新しいファームがあれば更新（USB 接続が必要。更新後に抜き差し） | ○ |
| アプリ更新 | 新しいバージョンの確認と更新、自動確認 | ○ |
| アプリの設定 | 言語（英語・日本語）、PC 起動時に自動起動、× ボタンで終了 or 最小化 | ○ |

## 5. F75 では使わない機能（ほかの機種・マウス用）

- 画面（液晶）に画像・アニメを送る機能（文言が中国語のまま）
- リアルタイムライト（文言が中国語のまま）
- マウス用: DPI、レート、ファイアーキー、マウスのライトなど

## メモ（ファーム書き換えとの関係）

- 公式アプリで変えられるのは「デフォルト」と「FN1」の割り当てまで。Fn キーそのものや固定の Fn 機能は変えられない。これが書き換えをする理由（`docs/roadmap.md`）。
- 自作ファーム（SMK）に書き換えると、公式アプリは使えなくなる見込み。ライトやマクロなど、上の機能のうち何を残したいかを ③ の GUI づくりの参考にできる。
